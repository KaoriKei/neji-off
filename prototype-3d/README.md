# NEJI OFF — 平面から始める金属のパズル

マットな金属のデザインで、平面のチュートリアルから360度回転できる六面キューブへ進む全11レベル。キューブでは色トレイと5枠の一時置きを全6面で共有する。

| レベル | 形 | 内容 |
|---|---|---|
| 1 | 平面・6本 | タップ、3本をそろえる、パーツを外す |
| 2 | 平面・12本 | 重なり、一時置き、トレイへの自動回収 |
| 3 | キューブ・18本 | 面ごとの単色配置、回転、内締めビス2か所 |
| 4 | キューブ・21本 | 追加プレート：全7枚 |
| 5 | キューブ・24本 | 二面の重なり：全8枚 |
| 6 | キューブ・27本 | 三面の重なり：全9枚 |
| 7 | キューブ・30本 | 四面の重なり：全10枚 |
| 8 | キューブ・33本 | 二段のプレート：全11枚 |
| 9 | キューブ・36本 | 重なる二つの面：全12枚 |
| 10 | キューブ・42本 | 六面の重なり：全14枚 |
| 11 | キューブ・45本 | 最後の分解：全15枚 |

クリア画面から次のレベルへ進む。やり直しは現在のレベルを初期化し、全レベルクリア後はLv1から遊び直せる。進行は保存せず、ページを開き直すとLv1から始まる。

## 起動

リポジトリのルートから実行する。

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5178
```

`http://127.0.0.1:5178/` を開く。

```sh
npm run build:3d
```

完成版だけを `prototype-3d/dist/` に出力する。`npm run build` は完成版と従来版をビルドし、本番用の配置を `dist/` に作る。

## 操作

- ネジをタップ：同色のトレイへ。空きがなければ5枠の一時置きへ。
- 同じ色が3本：トレイが交代し、一時置きにある同色のネジを回収する。
- パーツのネジを全部外す：そのパーツが外れる。
- キューブをドラッグ／左右の矢印：360度回転する。見えない裏面のネジを直接選ぶことはできない。
- 面番号の選択ボタンは置かず、ドラッグ・左右の矢印・「正面に戻す」で視点を操作する。
- 平面のチュートリアルは、盤面の手前に浮かぶカードと矢印で案内する。Lv3の回転案内は最初に回したら欄ごと消す。Lv4以降は案内欄を置かない。
- 通常時の説明文・素材名・操作の重複説明を省き、残り本数・一時置き・ボタンを13〜15pxへ拡大する。操作できない場合と重なりの確認中だけ短い通知を出す。次のトレイは先頭4色まで表示する。
- 青い円はポインターが重なっている操作対象を示す。クリックで抜く。頭同士の当たり範囲が重なるときは、ポインターに最も近い頭を選ぶ。
- 重なりを見る：パネルを広げて、頭・軸・受けナットの位置を確認する。確認中はビスを抜けない。
- 一手戻す：トレイの交代や連続回収を含めて前の状態に戻す。
- このレベルをやり直す：現在の盤面と履歴を初期化する。
- 最下段の商品紹介：タイヨウビス公式サイトを別タブで開く。

## 美術と範囲

- 基調は明るいグレー、マットシルバー、濃いグレーの金属。骨組みの接合部に少量の木を使う。
- ブランドのアクセント色は `#00AFCC`。ワッシャーは青・赤・紫・緑を使う。
- ビスの識別色は青 `#008EBC`・赤 `#BC304F`・紫 `#7438B8`・緑 `#228536`。盤面・トレイ・一時置きで同じ配色を使い、金属のグレーから見分けやすくする。
- ビスの外径を保って銀色の頭を小さくし、正面から見た色リングの幅を約1.6倍にする。色の部分は反射を抑えたマット塗装とし、トレイの色枠も2pxから4pxへ太くする。
- 既存のロジックで `yellow` と呼ぶ色を、試作では紫として表示する。既存ゲームの配色・データは変更しない。
- 穴・ネジ頭の十字溝・板の厚みは3D形状。材質、光、接触影で立体感を作る。
- 六面すべてにビスがある。外締めは頭を外側にし、フレームの耳の受けナットへ締め込む。六面の一部は内締めにし、頭を内側、軸とねじ山を外側に向け、パネル外側のナットへ締め込む。Lv3の折り返しは導入用の形状で、追加板のあるLv4以降は取り付けない。
- 内締めのビスは、どれかのパネルが外れてできた開口部から、頭が見えて届く向きで選ぶ。外側のナットを覆う折り返しは、内側の頭を抜くことを妨げない。特定の隣接面を先に外す条件は置かない。頭の側へ抜け、軸・ナットの側からは選べない。
- パネルを外した後もフレームの支持部と耳は残る。重なり確認時はパネルを広げ、フレームとの関係が見える。
- Lv4から、六面の外側に半分ほどの大きさの金属カバーを追加する。Lv8からは二段に重ね、Lv11は六面＋追加カバー9枚、合計15枚・45本。すべての板を外してクリアする。
- 追加板は支柱で下の板に固定し、周囲を折り下げて下のビス頭を覆う。上の板を外すと支柱と下の頭が現れる。支柱は下の頭・ナットとぶつからない位置に置く。覆い判定と表示は同じ寸法・座標を使う。
- 追加板を外しただけでは内部への開口部にならない。六面のどれかを外した後に内締めの頭へアクセスできる。
- 一時置き場は前回の平面試作の4枠から、今回は5枠に戻した。枠を減らさず、面同士のつながりで先読みを作る。
- 最下段に「タイヨウビス」「D6皿ドリル」「無溶接ビス」の紹介を置く。明るい金属の枠・ブルーのアクセント・ビスのイラストでゲームの見た目に合わせる。紹介先は https://taiyouvis.com/ 。
- 物理シミュレーションに勝敗を依存させず、確定したルールの結果を動きとして再生する。
- ネジを抜く動きは140ms、トレイへの飛行は260ms。同じ形状・材質の3Dネジを画面全体の描画層で曲線に沿って運び、到着時に正面向きと穴の大きさへ合わせる。盤面と飛行はひとつのWebGL描画器を共用する。
- パネルが外れる420msの動きはトレイの演出と並行する。パネルだけが動いている間は次のネジを抜けるが、一手戻す・やり直しはパネルが落ち着くまで待つ。
- 一時置きからの回収は1本180ms、開始を55msずつずらして重ねる。トレイ内の穴の幅はネジの有無で変えない。
- 見た目は生成モックアップを参考にした実際の3D表示。生成画像そのものを盤面として貼ってはいない。
- タッチ環境または `?light=1` では描画倍率を1にし、動的な影とアンチエイリアスを省く。通常の接触影は維持する。
- フォントはGoogle Fontsを利用し、取得できない場合はシステムフォントで表示する。

## 検証

```sh
npm test
node --import tsx scripts/verify-levels.ts
npm run build:3d
```

`cube-model.ts` が六面の向き・局所座標・留め具の関係を定義する。`layered-cube.ts` が追加板の寸法・支柱の座標・覆いを定義し、`layered-levels.json` がLv4〜11の配色・正解手順・検証値を保持する。`node --import tsx prototype-3d/choose-layered-levels.ts` で固定シードから再生成できる。`choose-cube.ts` は5枠を前提に配色とトレイ順を探索する開発用スクリプト。採用した配置と正解手順は `cube-study.json` にある。

既存の `Board` では、全てを外す必要のある覆いを `blockedBy`、どれか1枚が外れればよい開口部を `accessThrough` で指定する。キューブの内締めには後者を使い、実際の画面では頭の向きと遮蔽物も確認する。頭の向きは `headSide` に分け、覆い条件から推測しない。指定のない従来のレベルは従来どおり平面座標で判定する。

進行とチュートリアルは `campaign.ts`、描画は `flat-renderer.mjs` / `cube-renderer.mjs`、状態と履歴は `puzzle.ts`、トレイ等の表示は `app.mjs` が担当する。ビスを留める向きと抜く軸は `fastener-mount.mjs`、頭が重なるときの選択は `screw-hit.mjs` にまとめている。レベルを切り替えると、前の描画器と入力リスナーを解放する。

- 全11レベルを5枠で攻略可能。採用した正解手順を再生し、すべての板・ビスがなくなることを検証する。
- 元のゲームの難易度設計（`scripts/difficulty.ts`）を参考に、追加板の数・二段の重なり・配色とトレイ順で段階を作る。元の平面版のデータは変更しない。

| 4 | 2枠 | 9.0% |
| 5 | 1枠 | 24.8% |
| 6 | 2枠 | 39.0% |
| 7 | 2枠 | 47.5% |
| 8 | 2枠 | 57.8% |
| 9 | 2枠 | 74.3% |
| 10 | 3枠 | 75.3% |
| 11 | 2枠 | 91.0% |

- 詰み率は同じ方策を400回動かした目安（seed 36）。人間の失敗率ではない。最小仮置き数が毎面増える設計ではなく、重なりと誤った順番を選びやすい配色によって難しくしている。
- テスト46件、型検査、既存の全11面の検証、3D用ビルドが合格。追加板と覆いの一致、支柱の衝突回避、上下の取り外す順番、開口部の条件、一手戻すを検証。
- ブラウザーの390×844表示で、文字サイズ・横のはみ出しがないこと・5枠・最下段の商品紹介を確認。Lv1の6本、Lv2の12本を操作し、Lv3へ進む流れと回転後に案内欄が消えることを確認。
- Lv4の21本とLv11の45本は、回転・タップの画面操作で最後までクリア。追加板が外れた後のビスと内締めのビスを取り外し、Lv11の全クリア後はLv1へ戻れることを確認。描画キャンバスは1枚で、ブラウザーのエラー・警告はなし。
- Lv4の追加板とLv8の二段目は、取り外し・一手戻すで下のビスの表示と覆いが切り替わることを確認。今回、Lv5〜7・9〜10を各面通して画面操作した検証は未実施で、盤面ロジックは全11面を自動検証した。
- Android実機での今回の変更の動作確認は未実施。
